# TripMate — Travel & Tourism Planner

A responsive front-end travel planning demo built with HTML, CSS and JavaScript.

## Features
- Responsive landing page and destination cards
- Destination search and OpenStreetMap integration
- External hotel search links (Booking.com search results)
- Packing checklist saved with browser LocalStorage
- Travel tips and responsive layouts

## Run locally
Open `index.html` in a modern browser. An internet connection is needed for external map tiles, images and hotel search.

## Important limitations
- This is a front-end demo, not a real booking platform.
- It does not take payments or create hotel reservations.
- Map search opens an external map; embedded map is an overview and may not zoom precisely to every entered destination.
- The packing checklist is stored only in the current browser/device.

## Tech stack
HTML5, CSS3, JavaScript, LocalStorage, OpenStreetMap, Booking.com external search.
